# Security Policy

## Reporting a vulnerability

Please report security issues **privately** by emailing
[security@soublox.com](mailto:security@soublox.com). Do not open a public issue
for a security problem.

Include, as far as you can:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- the affected version (or commit) and your macOS version,
- any suggested fix.

We will acknowledge your report as quickly as we can and keep you updated while
we investigate. Please give us a reasonable window to ship a fix before any
public disclosure.

## Privacy guarantees

Eyes Driven 2me is built around a strict privacy promise:

- **100% on-device.** All processing happens locally on your Mac.
- **No network access.** The app makes no network requests and contains no
  telemetry, analytics, or crash reporting.
- **No camera frames are stored.** Frames are processed in memory and discarded;
  they are never written to disk or sent anywhere.
- The camera is only read while the app is enabled.

If you find any behaviour that contradicts these guarantees, please report it as
a security issue using the address above.
